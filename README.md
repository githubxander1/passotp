# Local Password OTP Vault

一个独立的 Edge Manifest V3 扩展，用于本地保存账号、密码和 TOTP。

当前版本：`0.10.3`

## 特性

- AES-GCM 加密保险库，主密码只用于本次解锁，不保存明文。
- 支持账号、密码、Base32 OTP 密钥。
- 支持 `otpauth://` URI、SHA-1/SHA-256/SHA-512、6/8 位和自定义周期。
- 支持密码生成、复制账号、复制密码和复制 OTP。
- 支持摄像头/二维码图片导入 `otpauth://`。
- 使用本地 `jsQR` 解码，不依赖 Edge 的 `BarcodeDetector`。
- 扩展弹窗内设置视图支持扫描当前标签页可见二维码、摄像头扫描和图片扫描。
- 支持逐行导入 Authenticator 的 `otpauth://` TXT 导出文件。
- 首页默认只显示含 OTP 的项目，可在设置页关闭筛选。
- 条目卡片采用紧凑布局，OTP 位于右上角，详情支持自动增高的备注输入框。
- 编辑项目使用独立弹窗视图，首页不显示可见滚动条。
- 支持导入未加密的 Bitwarden JSON 登录项目；OTP、密码、备注会转换到本地加密保险库。
- 编辑密码时支持显示/隐藏切换。
- 支持网页登录表单检测、匹配条目手动填充，以及登录后确认保存新账号。
- 登录页支持动态表单识别、单账号自动填充，以及提交后仅对新账号或密码变化的账号提示保存/更新。
- 填充时优先选择可见账号/密码字段，并兼容 React 等受控输入框的原生值追踪。
- 保存新增或修改项目后，会自动同步已保存的主 WebDAV 和备用 WebDAV 配置。
- 当前标签页扫码支持拖动框选二维码区域，适合同一页面有多个二维码的情况。
- 条目可绑定网站地址，网页填充只匹配相同站点，降低误填风险。
- 首页锁定按钮左侧提供 `otp` 筛选，设置页支持修改主密码。
- 支持加密 JSON 导出和导入。
- 支持主库和备用库两个 WebDAV 目标，配置使用独立本地密钥加密保存，不随主密码变化，单个目标失败不会阻断另一个目标。
- 远程保险库来自旧主密码时，手动同步支持输入旧主密码合并；旧主密码只在当前会话中使用，不会保存。自动同步无法询问旧主密码，检测到加密盐不一致时会跳过该远程库，避免覆盖旧数据。
- 坚果云根目录配置会自动使用 `password-otp` 子目录，并在写入前尝试创建目录。
- 解锁后在当前浏览器会话内保持解锁，浏览器关闭或手动锁定后失效。
- 不需要注册、登录或原生客户端。

## 同步说明

WebDAV 保存的是已经加密的保险库，服务器不会看到明文密码和 OTP。设置页可以填写一个主库和一个备用库，建议为两个目标使用不同服务或不同目录。首次在另一台设备使用时，可先导入 JSON，或在 WebDAV 同步时使用相同主密码完成合并。

OneDrive 需要单独注册 Microsoft OAuth 应用并配置客户端 ID，不能仅通过一个按钮直接授权。当前版本会明确提示这一点，导出/导入和 WebDAV 不依赖该配置。

## 加载

打开 `edge://extensions`，开启开发人员模式，选择“加载解压缩的扩展”，选择本目录。

## 项目结构

```text
src/
  background.js       # WebDAV、保险库后台操作、网页截图和区域扫码
  content.js          # 登录表单检测、填充提示、网页区域选择
  popup/
    popup.html        # 扩展面板
    popup.css         # 面板样式
    popup.js          # 本地保险库、OTP、设置和同步界面
  vendor/
    jsQR.js           # 本地二维码解码库
```

保险库和 WebDAV 配置只在本地加密保存；项目不包含服务端，也不会把主密码或 WebDAV 密码提交到仓库。

这是一个独立实现，只参考密码管理器的功能形态，没有复制其他扩展的代码或品牌资源。
